Excited to share that I have officially completed **Module 02: Linux, Security Tools & Controlled Reconnaissance** as part of my **Cybersecurity & Ethical Hacking Virtual Internship** at **Codomax Digital Solutions**! 🎯

In this module, I transitioned from foundational security theory into deep, practical, hands-on offensive & defensive exploration. Reconnaissance is where every security assessment begins—and mastering how to safely enumerate assets, analyze network packets, and inspect application traffic is a game-changer.

Here is a summary of what I worked on and built during this module:

🐧 **Linux Security & Administration**:
- Deep dive into the Filesystem Hierarchy Standard (FHS), path resolution, and Discretionary Access Controls (DAC).
- Audited special permission bits (**SUID, SGID, and Sticky Bits**) and understood their critical role in local privilege escalation vectors.
- Analyzed authentication architectures (`/etc/passwd`, salted password hashes in `/etc/shadow`, and secure `sudoers` administration via `visudo`).
- Monitored processes and system services with `ps`, `top`, `kill`, and `systemctl`.

🔍 **Active & Passive Reconnaissance Methodologies**:
- Contrasted non-intrusive OSINT footprinting (WHOIS registrar lookups, DNS record queries using `dig` & `nslookup`) with active perimeter scanning.
- Evaluated risk profiles and detection footprints across the cyber attack lifecycle.

🛠️ **Essential Security Tools in Action**:
- **Nmap**: Conducted TCP SYN (`-sS`), service version detection (`-sV`), OS fingerprinting (`-O`), and Nmap Scripting Engine (NSE) audits against authorized targets (`scanme.nmap.org`).
- **Wireshark**: Captured and dissected live packet flows, traced TCP 3-way handshakes (SYN $\rightarrow$ SYN/ACK $\rightarrow$ ACK), and crafted targeted display filters for DNS, ARP, and cleartext HTTP streams.
- **Burp Suite**: Configured interception proxies, examined request/response lifecycles, replayed altered headers in Repeater, and decoded cryptographic strings.
- **OWASP ZAP**: Automated passive and active baseline web scans, evaluated spidering mechanisms (Traditional vs AJAX Spider), and mapped security header deficiencies.

⚙️ **Custom Automation & Lab Report**:
- Developed `recon_lab.sh` — a safe, modular Bash automation script for controlled host discovery, DNS mapping, and fast service enumeration with built-in authorization verification.
- Documented our findings, risk analysis (CVSS v3.1 / OWASP Top 10 alignment), and concrete server hardening recommendations in a comprehensive technical lab report.
